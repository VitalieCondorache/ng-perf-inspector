# ng-perf-inspector 🚀

A lightweight debugging and performance monitoring toolkit designed for modern Angular applications.

## Features
* **HTTP Performance Interceptor:** Measures request duration, logs response times, and catches errors with styled console outputs.
* **Component Render Tracker:** Uses Angular Signals to track performance and detect potential UI bottlenecks.
* **Dev Overlay:** A simple floating widget for development mode.

## Installation
Clone the repository and integrate the modules into your Angular project providers and components.
